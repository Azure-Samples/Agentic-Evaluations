# Contributing

This project welcomes contributions and suggestions. Contributions help improve the quality,
usability, and reach of Azure samples.

Most contributions require you to agree to a **Contributor License Agreement (CLA)** declaring
that you have the right to, and do, grant us the rights to use your contribution.

For more information, visit https://cla.opensource.microsoft.com.

When you submit a pull request, a CLA bot will automatically determine whether you need to
provide a CLA and will decorate the PR accordingly (for example, with a status check or comment).
Simply follow the instructions provided by the bot. You only need to complete this process once
across all Microsoft repositories.

## Reporting Issues and Bugs

If you find a bug in the source code or an issue in the documentation, please help by
[opening an issue](https://github.com/Azure-Samples/Agentic-Evaluations/issues/new).

Before submitting a new issue:
- Search existing issues to avoid duplicates
- Check whether the issue has already been reported or resolved

When filing an issue, please include as much of the following information as possible:

- **Overview of the issue** (error messages and non‑minified stack traces are helpful)
- **Version** affected (if applicable)
- **Motivation or use case** explaining why the behavior is unexpected
- **Environment details** (OS, browser, Azure service, SDK version, etc.)
- **Steps to reproduce** the issue clearly
- **Related issues** (if any)
- **Suggested fix** (optional, if you have insights)

Clear, well‑scoped issues help maintainers respond more quickly.

## Feature Requests

Feature requests are welcome.

To request a new feature:
- Open an issue describing the proposed feature
- Explain the problem it solves and why it would be useful

If you plan to implement a larger feature yourself, please open an issue first to discuss
the proposal before starting significant work.

Small enhancements or improvements may be submitted directly as pull requests.

## Submitting Pull Requests

We welcome pull requests for bug fixes, enhancements, documentation improvements,
and new or improved samples.

Before submitting a pull request, please:

1. Search existing pull requests to avoid duplicating work  
   https://github.com/Azure-Samples/Agentic-Evaluations/pulls
2. Fork the repository and create your branch from `main`
3. Make your changes following existing code and documentation patterns
4. Use clear, descriptive commit messages
5. Ensure samples:
   - Are easy to understand and run
   - Do not include secrets, credentials, or sensitive data
   - Use synthetic or non‑sensitive datasets only
   - Preserve OSS telemetry disclosure and opt-out instructions documented in README
6. Push your fork and submit a pull request to the `main` branch
7. Be responsive to feedback during the review process

A maintainer will review your pull request and may request changes before merging.
